GUIDE / 01

Prefixes and command syntax

The default command prefix is ;. Put it before a command name, then add arguments separated by spaces. Replace the example prefix with your own if you changed it.

;help
;ping
;setprefix !
!help

Read command arguments

  • <value> means a required argument. Example: ;setprefix <symbol>.
  • [value] means an optional argument. Example: ;config [page].
  • on|off means choose one of the listed values, without typing the pipe. Example: ;autodelete off.
  • ... means more than one value may be supplied.

Examples:

;echo hello Aria
;config 2
;autodelete delay 5
;rpc playing name="My Game" details="Ranked match"

Text commands join the remaining words into one message. For RPC key/value arguments, put multiword values in quotes. Prefixes can be 1 to 5 non-space characters; setprefix with no argument shows the current prefix.

GUIDE / 02

Keep tokens private

The bot needs a token to authenticate. Keep it on the bot host and submit it only through a trusted, HTTPS-protected instance setup flow. Never send tokens in chat, screenshots, or support requests. Aria encrypts sensitive values in its local config when the cryptography dependency is installed.

REFERENCE / LIVE COMMANDS

Bot commands

Examples use the default ; prefix. Replace it with your configured prefix. Use ;helpwall in the running bot for its complete registered command list.

COMMANDS / HELP AND DISCOVERY

;help [topic]Aliases: ;h, ;commands

Show help. Topic pages include RPC guides such as ;help rpc music, ;help rpc activity, and ;help rpc tools.

;helpwallAlias: ;wallcmds

List the commands registered in the current runtime, grouped into pages.

;quickhelpQuick reference

Show a short overview of loaded commands. Use ;helpwall for the full live list.

;cmdinfo <command>Command details

Look up a registered command by name to see its aliases and active status.

;categoriesCommand overview

Show the runtime command count and a category-style breakdown.

COMMANDS / SETTINGS

;pingAliases: ;ms, ;latency, ;lat

Report API, gateway, and website latency.

;setprefix <symbol>Alias: ;prefix

Change the command prefix. Use 1 to 5 non-space characters; run without an argument to display the current prefix.

;config [page]Alias: ;cf

View runtime configuration and status pages. The dashboard provides the visual controls.

;autodelete on|offAlias: ;ad

Enable or disable automatic deletion of command replies. Set the delay with ;autodelete delay <seconds>.

COMMANDS / UTILITIES

;echo <text>Text utility

Send the supplied text back as a formatted response.

;length <text>Text utility

Show the character and word count for the supplied text.

;timeDate and time

Show the current date, time, and Unix timestamp.

;hash <text>Aliases: ;md5, ;sha256

Generate a text hash. Choose an alias to select the hash algorithm.

COMMANDS / TEXT TOOLS

;bold <text>Also: italic, underline, strike, code, spoiler

Format text as bold, italic, underlined, struck through, inline code, or spoiler text.

;upper <text>Also: ;lower, ;mock

Convert text to uppercase or lowercase, or apply alternating-case formatting.

;reverse <text>Also: ;flip

Reverse text or render it using the available upside-down character mapping.

;base64encode <text>Also: ;base64decode

Encode text as Base64 or decode a Base64 string.

COMMANDS / PRESENCE

;rpcAlias: ;rich_presence

Run ;rpc for usage. Help topics include ;help rpc activity, ;help rpc music, ;help rpc custom, and ;help rpc tools.

;rpc preset save|load|list|delete <name>Presence presets

Save an activity by name, list saved presets, load one, or delete it.

;rpc rotation set <seconds> <preset,...>Also: start, stop, status, clear

Configure a timed rotation of saved presets, then start or stop it.

;rpc stack add <type> [key=value ...]Up to five activities

List, add, remove, apply, or clear stacked activities. Quote values containing spaces.

The dashboard is the browser control surface for the Aria process running on its configured host. Use it to inspect status and manage the features enabled for that account.

TROUBLESHOOTING / BOT

Commands are not responding

Confirm Aria is running and connected, check the current prefix with ;setprefix, then try ;ping. Use ;helpwall to confirm a command is registered.

TROUBLESHOOTING / COMMANDS

The command prefix is not working

The default prefix is ;, but it can be changed. Run ;setprefix with no argument in the current prefix to see the configured value.

TROUBLESHOOTING / PRESENCE

Presence is not updating

Run ;rpc for supported syntax, then use the matching ;help rpc topic. Quote multiword values in key/value activity arguments.
