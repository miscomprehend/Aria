ARIA / QUICK ANSWERS

Frequently asked questions

Bot commands, account safety, and runtime controls.

How do I find the bot's commands?

Use ;help for command topics and ;helpwall for the complete list registered by your running instance. Browse command help.

Where does the Aria bot run?

The bot runs on its configured host. Use the browser dashboard to view and manage that runtime; public help and feature pages are available here on the website.

How should I handle bot tokens?

Keep tokens private and submit them only through a trusted, HTTPS-protected instance setup flow. Never include a token in screenshots, chat, or support requests. Read the token safety guide.
